这是自习室预约系统的完整数据库结构 school.sql，已经严格按照三大范式设计：

表结构：
- room：教室
- seat：座位（room_id 外键关联 room，联合唯一约束 room_id+x+y）
- student：学生
- orders：订单（关联 student + seat，不冗余 room_id）

约束：
1. 同一个教室下 x+y 坐标唯一
2. 所有外键约束完整
3. 无冗余字段
4. InnoDB + 索引齐全
5. 订单状态：0待签到 1使用中 2已完成 3违约 4取消

项目是 Flask 后端，任务四需要：
1. 座位批量初始化接口（事务批量插入）
2. 实时座位状态多表联查 API
3. 一人一单、同座位时段冲突校验
4. 预约事务 + SELECT ... FOR UPDATE 行级锁
5. 管理端订单列表（多表联查）
6. 强制取消订单 API
7. 每分钟定时任务自动标记超时未签到订单为违约
